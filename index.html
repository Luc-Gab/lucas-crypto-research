Research Portfolio

Selected Research Cases

Each case study is structured around fundamentals, catalysts, risks and variables that could affect the medium- and long-term thesis.

Case Study 01

Ethereum — Settlement & Smart Contract Infrastructure

Thesis

Ethereum represents a major smart-contract and settlement infrastructure ecosystem, with a large developer and application base.

Key Catalysts

Scaling improvements, Layer-2 growth, application adoption, staking economics and ecosystem development.

Key Risks

Competition, changing network economics, regulatory uncertainty and technological execution.

Case Study 02

Solana — High-Throughput Blockchain Ecosystem

Thesis

Solana focuses on high-throughput blockchain applications and has developed a broad ecosystem across DeFi, consumer applications and infrastructure.

Key Catalysts

Network activity, developer growth, applications, infrastructure improvements and ecosystem expansion.

Key Risks

Competition between Layer-1 networks, network reliability, valuation and ecosystem concentration.

Case Study 03

Chainlink — Oracle & Interoperability Infrastructure

Thesis

Oracle infrastructure can become increasingly important as blockchains interact with external data and traditional financial systems.

Key Catalysts

Adoption of decentralized data services, interoperability and institutional blockchain infrastructure.

Key Risks

Competition, adoption rates, technological changes and token value-capture dynamics.

Case Study 04

Aave — Decentralized Lending

Thesis

Aave provides decentralized lending infrastructure and is a useful case study for analyzing DeFi liquidity and protocol economics.

Key Catalysts

Growth in decentralized lending, liquidity, new markets and protocol development.

Key Risks

Smart-contract risk, liquidity stress, regulatory changes and competitive pressure.

Case Study 05

Sui — Emerging Layer-1 Infrastructure

Thesis

Sui is an emerging Layer-1 ecosystem whose development can be studied through technology, developer activity, applications and token economics.

Key Catalysts

Developer adoption, ecosystem expansion, application growth and network activity.

Key Risks

Competition, token unlocks, adoption uncertainty and ecosystem maturity.
